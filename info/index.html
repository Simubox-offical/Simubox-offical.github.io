ABOUT THIS HUB

A small collection of browser experiences

What is this?

This hub keeps a few standalone web projects in one place. Pick a destination from the home page to launch an experience, or use the details below to see what each section contains.

Destinations

  • PPG — a People Playground browser build with a Windows XP-inspired loading screen.
  • DELTARUNE — a chapter select menu with Chapters 1–4 available and later chapters marked as coming soon.

Credits

The Deltarune menu credits the browser port to bog. The experiences load some of their original assets from their respective project hosts.
